# 🌾 WeedScan — ตรวจจับวัชพืชในนาข้าวด้วยโดรนและการเรียนรู้เชิงลึก

เว็บเดโมของปริญญานิพนธ์ — อัปโหลดภาพถ่ายทางอากาศจากโดรน แล้วระบบจะตรวจจับวัชพืชด้วย YOLO11s (โมเดลรอบที่ 12 · v7)
(เลือกใช้ SAHI สำหรับวัชพืชต้นเล็กได้) และสร้างแผนที่กำหนดการพ่น (Prescription Map) 3 ระดับ

| ตัวชี้วัด (ชุดทดสอบภาพนาไทย 140 ภาพ, SAHI 1024) | ค่า |
|---|---|
| mAP50 | 70.2% |
| mAP50-95 | 31.1% |
| Precision | 65.6% |
| Recall | 67.8% |
| F1 ระดับช่องกริด | 89.3% |
| ไม่ใช้ SAHI: mAP50 | 65.9% (เร็วกว่าประมาณ 8 เท่า) |

**ผู้จัดทำ:** นายอรรถวิทย์ หมัดสอิ๊ด · **อาจารย์ที่ปรึกษา:** ผศ.ดร.วสุ อุดมเพทายกุล
สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง

## ไฟล์
- `streamlit_app.py` — หน้าเว็บ (Streamlit)
- `weedscan_core.py` — ตรวจจับ (YOLO11s / SAHI), วาดผล, สร้างแผนที่กำหนดการพ่น
- `weed_best.pt` — น้ำหนักโมเดล v7 (YOLO11s, imgsz 1024 · ต้องใช้ ultralytics ≥ 8.4)
- `examples/` — ภาพตัวอย่างจากแปลงนาไทย
